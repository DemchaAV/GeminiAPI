# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities by emailing demchaav@gmail.com.

Do NOT open a public GitHub issue for security vulnerabilities.

You should receive a response within 48 hours. We will work with you to understand the issue and coordinate a fix and disclosure timeline.
